# Security policy

## Supported versions

Only the latest release gets fixes. Update first, then report.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository: <https://github.com/jrmatherly/claude-multipass/security/advisories/new>. Do not open a public issue.

Never include a token, a Keychain item or a profile folder in a report. Describe the steps and the versions of macOS, Claude Desktop and this tool.

## Scope

- The script, `bin/claude-multipass`.
- The menu bar app, Claude Multipass.
- The release workflow, `.github/workflows/release.yml`.
- The update feed, `appcast.xml` in `jrmatherly/homebrew-tap`.
