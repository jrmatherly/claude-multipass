# Doctor cleanup implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn off the Claude Code add-ons that `/doctor` found unused on 2026-11-15, and trim two blocks of `CLAUDE.md` that a session can rebuild from the repo, so every session in this project starts with about 6k fewer estimated tokens of context.

**Architecture:** Every change is a key in a JSON settings file or a deletion in `CLAUDE.md`. Each task copies the file it edits first, writes through a temp file that `jq empty` has parsed, and ends with a `jq` or `grep` check. Nothing is uninstalled, so each task is undone by restoring the copy or flipping the key back.

**Tech stack:** `jq`, `claude-stack` (`~/dev/dotfiles/bin/claude-stack`), `git`, the `/context` command.

**Spec:** None. The `/doctor` report of 2026-11-15 is the source, and the Evidence section below carries every figure the tasks use.

## Global constraints

- No plugin, skill or MCP server is uninstalled or removed. Never run `claude mcp remove`, which deletes the server config and its OAuth tokens.
- Read settings files by key only (`jq '.enabledPlugins'`). `~/.claude/settings.json` and `~/.claude.json` hold secrets in `env` and `headers`. Never print a whole file.
- User-scope edits go to `~/.claude/settings.json`. Project-scope edits go to `.claude/settings.local.json` (git-ignored) and the project entry in `~/.claude.json`. Never edit `.claude/settings.json` for this plan.
- `.claude/rules/skill-stack.md` and `.claude/skill-stack.json` are generated by `claude-stack` and git-ignored by `~/.gitignore`. Change them only through `claude-stack`.
- `pnpm check` runs `prettier --check` over `**/*.json`, and `.prettierignore` does not list `.claude/skill-stack.json`. `claude-stack` writes that file in a style prettier rejects, so the commit gate fails after every `claude-stack apply` until `node_modules/.bin/prettier --write .claude/skill-stack.json` runs (seen on 2026-11-15).
- This plan's only tracked change is `CLAUDE.md`, which is Markdown, so it commits and pushes on `main` with no branch or PR. Run `git commit` and `git push` in separate calls. The commit gate runs `pnpm check` (56 s typical) before the commit.
- Token figures are estimates (characters divided by 4).
- The key names `skillOverrides` and `disabledMcpServers` come from the `/doctor` command text. They were not found in the local docs cache, so Task 7 confirms each one by observing a new session.

## Review focus

1. A running Claude session rewrites `~/.claude.json` and drops the Task 3 edit. Expected: the key is still there 60 seconds later and in a new session. Task 3 step 4 checks the first, Task 7 the second.
2. A write leaves a settings file that does not parse, and Claude Code then ignores the whole file. Expected: no file is replaced before `jq empty` passes on the temp copy. Every write step does this.
3. A plugin or skill turned off everywhere is one that another project's `skill-stack.md` picks. Expected: that name is dropped from the list. Task 1 step 1 checks.
4. `claude-stack apply --off` rewrites more of `skill-stack.md` than the three new lines. Expected: `diff` against the copy shows three added list items and nothing else. Task 4 step 3 checks.
5. The release pointer in `CLAUDE.md` drops a fact that `.claude/skills/release/SKILL.md` does not hold. Expected: each removed fact is found in the skill first. Task 5 step 3 checks.
